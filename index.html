Alexa Device Manager

Lokales Werkzeug zum Anzeigen, Filtern, Sichern und kontrollierten Löschen von Alexa-Smart-Home-Geräten. Es läuft direkt in deiner Amazon/Alexa-Browser-Session.

Start

  1. Öffne alexa.amazon.de Geräte-JSON.
  2. Dort F12 drücken und zur Console wechseln.
  3. Unten den kompletten Code kopieren und in die Console einfügen.
  4. Das Overlay lädt die Geräte automatisch.
