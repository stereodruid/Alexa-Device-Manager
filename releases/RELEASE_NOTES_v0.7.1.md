- Removes the unnecessary `tabs` and `activeTab` permissions.

- Includes updated Chrome Web Store assets for the current interface.

Downloads:

- `Aura-Device-Master-v0.7.1-Chrome-Web-Store.zip` — package for the Chrome Web Store dashboard
