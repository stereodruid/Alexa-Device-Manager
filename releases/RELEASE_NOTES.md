# Alexa Device Manager v0.6.0

![Release Preview](https://raw.githubusercontent.com/stereodruid/Alexa-Device-Manager/main/assets/preview_popup.png)

## What's New 🚀
- **Global Amazon Region Support:** The extension now dynamically detects your language settings and redirects you to your corresponding Amazon regional domain (e.g. mazon.com, mazon.de, mazon.co.uk, etc.).
- **Manual Country Selector:** A new dropdown menu in the popup allows you to manually select your desired Amazon region before opening the manager, making it perfect for international users or travelers.
- **Redesigned App Icon:** We've updated the extension with a sleek, dark-themed, transparent smart speaker icon for better integration into modern browser themes.
- **Updated Permissions:** Added host permissions for all 12 major Amazon Alexa regional endpoints.

## Bug Fixes 🐛
- Resolved an issue where non-German users were hard-redirected to mazon.de, causing authentication issues and breaking the extension for international use.

*Download the AlexaDeviceManager.zip below and load it as an unpacked extension in Chrome!*
